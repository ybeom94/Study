## 🎯 Learning Goals

### ☕ Java
- Java 기본 문법 및 객체지향 프로그래밍 이해
- Java 표준 라이브러리와 데이터 처리 기능 활용
- 멀티스레드, 네트워크, 데이터베이스 연동 이해
- Java를 활용한 응용 프로그램 개발 능력 확보

### 💻 CS
- 컴퓨터의 구조와 명령어 실행 과정 이해
- CPU, 메모리 및 저장장치의 동작 원리 이해
- 운영체제의 프로세스 및 자원 관리 원리 이해
- 동기화, 교착 상태, 가상 메모리, 파일 시스템 이해
